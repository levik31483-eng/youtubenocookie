# YouTube No Cookie Player

A small, dependency-free web app that converts a YouTube video link to a
privacy-enhanced `youtube-nocookie.com` embed and starts playback in fullscreen.

## Run it

Open `index.html` in a browser, or serve this folder with any static web server.
Fullscreen and clipboard access work best from `localhost` or an HTTPS origin.

Paste a YouTube watch, `youtu.be`, Shorts, or Live link and choose **Play
fullscreen**. If the browser blocks fullscreen, use the button below the player
or the YouTube player controls. Some videos may not allow embedding.
